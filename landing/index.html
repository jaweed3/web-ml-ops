THE MISSION

Built for teams who don't ship notebooks.

RescueVision is a repeatable, auditable, observable ML pipeline. It trains a YOLOv8n model, quantizes it for edge deployment, benchmarks it against quality gates, registers it in a model registry, and serves it behind a hardened FastAPI inference server with full observability.

THE PIPELINE

5 stages. One deterministic DAG.

Each stage is cacheable, reproducible, and tracked. Change one input, DVC knows exactly what to rebuild.

Stage 1
Data — Ingest & Validate
Pulls versioned COCO person subset from DagsHub via DVC. Validates structure, image/label count parity, YOLO label format, and 10 random image corruption checks. Debug mode generates synthetic data — no DVC pull needed.
dataset_hash.txt
Stage 2
Train — YOLOv8n Training
Device-adaptive training via Ultralytics API — CUDA (RTX 4060), MPS (Mac Mini M4), or CPU fallback. Every hyperparameter and metric logged to MLflow on DagsHub.
best.pt → MLflow artifacts
Stage 3
Export — Quantize & Convert
Converts best.pt into three edge-optimized formats: ONNX FP32 (~12 MB), ONNX INT8 (~3.2 MB) via dynamic quantization, and TFLite INT8 (~3 MB). TFLite skipped gracefully if TensorFlow is absent.
model.onnx · model_int8.onnx · model.tflite
Stage 4
Benchmark — Measure & Validate
Runs ONNX Runtime inference on 100 validation images per format. Measures mean/p95 latency, model size, and actual mAP50 via YOLO validation backend. Writes structured report consumed by Stage 5.
benchmark_report.json
Stage 5
Register — Quality Gate & Registry
mAP50(INT8) ≥ mAP50(FP32) × 0.97. If gap exceeds 3%, the pipeline fails — no exceptions, no manual override. On pass: all 3 formats registered to MLflow Model Registry with git_commit, dataset_hash, and pipeline tags.
MLflow Model Registry

QUALITY GATE

We don't ship degraded models.

If INT8 quantization drops accuracy more than 3%, the pipeline fails. No exceptions. No manual override. The model never reaches production.

97 %
PASS — mAP50(INT8) ≥ 97% of FP32
FAIL — Pipeline exits 1. Telegram alert sent.
